## 0. 与初版计划的偏差（已核对源码，以此为准）

| 项 | 初版计划写的 | 源码实际 | 处理 |

## 3. 必须逐条落地的行为（源码行号对应）

### 3.1 路径工具
- `lp(path)`（L134）：Windows 下路径 `len>=230` 时加 `\\?\`；UNC 用 `\\?\UNC\`。
- `normalize_instance_path()`（L503）：用户可能选了**含 `.minecraft` 的上一层**；若该目录 `looks_like_instance()==0` 而 `<它>\.minecraft` 命中了，自动下钻并提示「所选目录里没有实例文件，已自动改用子目录：…」。
- `looks_like_instance()`（L490）：对全部 25 项 `path_exists` 打分，>0 即像实例。

### 3.2 体积估算（**不能卡界面**）
- `quick_size(path, max_files=3000, max_seconds=0.5)`（L244）：**超过 3000 个文件或 0.5 秒即中止**，返回 `(字节, 文件数, 是否截断)`。
- `size_note()`（L278）文案格式：
  - 文件：`文件，1.2 MB`
  - 文件夹截断：`文件夹，≥ 1.2 GB（未扫完）`
  - 文件夹正常：`文件夹，约 1.2 GB / 128 个文件`
- `human_size()`（L169）用 1024 进制。

### 3.3 相同判定与复制（核心，L301-L365）
- `VERIFY_LIMIT = 4 * 1024 * 1024`。
- `files_identical(a,b)`：**先比 size 与 mtime（秒级整数），不相等直接 False**；**size > 4MB 直接 False（保守重写）**；否则按 **256 KB 分块**比内容。
- `copy_one_file()`：目标存在 → 相同则 `same++` 且跳过；否则 `_force_writable(dst)` 后 `copy2` 覆盖 → `over++`、`bytes += size`。目标不存在 → 建父目录后复制 → `new++`。
- 任何异常 → `failed++` 并把 `复制失败：<src> → <dst>（<原因>）` 记进 `errors`，**不中断**。
- `_force_writable()`（L293）：`chmod | 0o200` 去掉只读，失败静默忽略。
- **移植增强（用户已同意流程中的「原子替换」）**：写盘时先复制到同目录临时文件再 `Files.move(..., ATOMIC_MOVE/REPLACE_EXISTING)`，避免游戏中途崩溃留下半截文件；但**统计语义与跳过语义不许变**。

### 3.4 合并覆盖（L368-L424）
- 文件夹 → 合并：同名覆盖、**目标独有文件保留不删**；先 `makedirs`。
- **类型冲突**：源是 dir 而目标是 file → 删除目标文件并按文件夹转移，日志「提示：目标位置 %s 原本是文件，已删除后按文件夹转移。」；源是 file 而目标是 dir → `rmtree` 后按文件转移，日志「提示：目标位置 %s 原本是文件夹，已删除后按文件转移。」；删除失败则 `failed++` 并**return**（不继续）。
- 每个文件与每个目录前都检查 `cancel.is_set()`，命中抛 `TransferCancelled`。
- 读取文件夹失败（`err`）→ `failed++` + `读取文件夹失败：<路径>（<原因>）`，continue。
- **缺失项安全跳过**：`copy_item` 对不存在的源**不报错、不产生空目录**（自检断言 L1340）。

### 3.5 统计
`new / over / same / failed / bytes / errors`（L427），`merge_stats` 合并（L431）。

### 3.6 扫描（L445-L471）
- `present`：默认项中存在（类型必须匹配：dir 判 `is_dir`、file 判 `is_file`）。
- `missing`：默认项中不存在 → 原因 `类型不符`（路径在但类型不对）或 `不存在`。
- `extras`：`OPTIONAL_ITEMS` 中存在的项（连同默认勾选态）。
  ⚠️ 注意：`extras` **只包含存在的项**，不存在的不显示。

### 3.7 备份与主流程（`TransferRunner`，L519-L624）
- 备份目录：`<目标实例>\_转移备份_yyyyMMdd_HHmmss\`（**注意是「转移备份」不是「迁移备份」**）。
  若同名目录已存在，追加序号：`_转移备份_<时间戳>_1`、`_2`… 直到不冲突（py L565-L569）。
- 只备份「**目标侧已存在**」的条目：`todo = [it for it in items if path_exists(dst/item)]`；
  `todo` 为空时日志「新实例里没有与转移列表同名的内容，无需备份。」
- 备份时 **`skip_same=False`**（备份必须真拷，不跳过），统计并入总 stats，日志
  「备份完成：%d 个文件（约 %s）。」（此处 `%d` 取 `bstats["new"]`）。
- 主流程顺序（L540-L618）：
  1. `phase("正在统计文件…", True)` → `count_items` 全量统计 → 日志「本次转移 %d 项，共 %d 个文件（约 %s）。」
  2. 备份（可选，见上）
  3. `phase("正在转移数据…", False)` → 逐项 `copy_item(skip_same=True, on_file=进度回调)`
     每项日志「→ 转移 <名称>（文件夹/文件）」+「   <名称>：新增 %d，覆盖 %d，相同跳过 %d[, 失败 %d]」
  4. `done` 消息：`stats`、`per_item`、`backup_dir`、`elapsed`、`file_count`、`size`；
     结束前把进度推进到 `(total, max(total,1))`。
- 取消：捕获 `TransferCancelled` → 日志「已取消（已经复制的内容不会回滚）。」→ 发 `cancelled` 消息（带 stats）。
- 未预期异常 → 发 `error` 消息（带完整 traceback），**不许静默吞掉**。
- 进度回调 `on_file()` 在**每个文件之后**自增（相同跳过、失败也算），所以进度分母是 `max(total,1)`。

### 3.8 取消
`cancel` 事件置位后转移线程以 `cancelled` 消息结束（L1414）。

## 4. py 自检里那些「踩过坑」的断言（Java 测试必须等价覆盖）

| 用例 | 断言 |
|---|---|
| 大小/时间完全相同、内容不同（1024B 与 4MB+4096B 两种） | **必须覆盖**（v1.1 的真实缺陷） |
| 再跑一次相同源 | `same==1`（小文件跳过）且 `over==1`（超大文件保守重写），`failed==0` |
| 幂等 | 第二次 `over==0`、`failed==0` |
| 目标独有文件 | 覆盖后仍存在（`config/keep.toml`、`saves/other/level.dat`） |
| 子目录 | `config/sub/b.toml` 正确新增 |
| 未勾选的 `mods` | 目标里不该出现 |
| 源缺失项 | 目标里不产生空目录 |
| 备份 | 备份里是被覆盖前的旧内容 |
| 取消 | 能中止 |
